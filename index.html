How It Works

The real project follows these three steps.
1
Read contributions

Read annual contribution data through the GitHub API.

2
Generate anime SVG

Render the heatmap, OC state, dialogue, and heartbeat into SVG.

3
Deploy to Pages

GitHub Actions publishes the output branch for README embedding.

Once the SVG is generated, your README only needs one line.
